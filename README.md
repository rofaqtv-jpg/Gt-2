# Open City Mini

A small legal Android open-city prototype inspired by driving/action games.

This project is **not** GTA V and not affiliated with Rockstar Games.

## Features

- Top-down city
- Player movement with virtual joystick
- Shooting
- Cars
- Pedestrians
- Police
- Wanted stars
- Missions
- Money and health
- Procedural graphics only

## Build with Android Studio

1. Open the folder in Android Studio.
2. Let Gradle sync.
3. Run on an Android device or emulator.

If Gradle is installed:
